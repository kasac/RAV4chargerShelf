# Grasshopper definitions

Save your Grasshopper definitions here.

- **Single Script component** (simplest, no repo needed): paste `rhino/rav4shelf_rhino.py` into a
  Python 3 Script component. See [docs/grasshopper_onboarding.md](../docs/grasshopper_onboarding.md).
- **Repo-linked wrappers** (for working on the code): save the definition here as
  `RAV4chargerShelf.gh`. The wrappers find the Python code (`../src`) relative to this folder. See
  [docs/grasshopper_setup.md](../docs/grasshopper_setup.md).
