# Grasshopper definition

Save the working definition here as **`RAV4chargerShelf.gh`**. The wrapper components find the
Python code (`../src`) relative to this folder.

Build it by following [docs/grasshopper_setup.md](../docs/grasshopper_setup.md) (about 10
minutes). The `.gh` holds only thin wrappers, pasted from `rhino/gh_components/*.py`. All logic
stays in `src/rav4shelf/`.
